\section{Each leaderboard, and alternative analyses}
\label{sec:perbench}

\subsection{Each leaderboard}

Table~\ref{tab:perbench} gives each leaderboard's numbers.
The leaderboards do not lean one way: five estimates lie above 1 and five below, ranging from \BenchJOR{} on \bench{gpsanant/ecdsafail-challenge} to \BenchCOR{} on \bench{eigenlabs/eip8200-challenges/modexp}.
Between 19 and 46 participants per leaderboard had both successes and failures, which is what the comparison needs.
On nine leaderboards some of those participants only ever built on one kind of parent, so they help with the time trend and other adjustments but not with the comparison itself.

As a data check, I recomputed which submissions should have been promoted from their scores, and the recomputation matched Yukon's records on \ATFiveReproduced{} leaderboards (Section~\ref{sec:outcomes}).
On \ATFiveNotReproducedList{} it disagrees on more than 1\% of submissions, apparently because the promotion threshold changed part-way through, so the analysis uses Yukon's recorded promotions there, as the plan requires.

\subsection{Alternative analyses}

A result can depend on judgment calls, so the plan fixed nine alternative versions of the analysis in advance, each changing one call (Section~\ref{sec:sensitivity}).
Table~\ref{tab:sensitivity} and Figure~\ref{fig:sens} show them.
Every version gives a combined odds ratio between 1.01 and 1.03, and every 90\% interval stays inside the pre-registered range, so no single judgment call changes the answer.
Version 2 asks a slightly different question, whether the immediate code parent matters rather than the declared starting point, and agrees too.
Version 7 is identical to the main result: the author's \AuthorRows{} submissions are all on ECDSA.Fail, and the three that are analysis rows predate its confirmatory window.
Version 8 keeps one leaderboard from each pair of closely related leaderboards and combines eight.

Unknown model labels are concentrated on one leaderboard.
On \bench{eigenlabs/flock-challenge}, \FlockUnknownCell{} of \FlockAnalysisRows{} analysis rows are cross-solver rows with an Unknown or Multi family on one side, and in \FlockUnknownParent{} of them it is the parent's family that is missing.
Version 1, which treats Unknown as a company of its own, moves that leaderboard's odds ratio from \BenchEOR{} [\BenchEORLow{}, \BenchEORHigh{}] to \FlockSOneOR{} [\FlockSOneLow{}, \FlockSOneHigh{}].
This per-leaderboard figure is descriptive; the plan reports only the combined value for version 1.
